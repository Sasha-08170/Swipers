# Компонент слайдер — Swiper

Интерфейс выполнен в тёмном стиле с использованием **Flexbox** и **адаптивной верстки**.

### Основные особенности:
- Карточки участников с фото, должностью, навыками и бейджами уровня.  
- Плавная анимация при наведении (hover-эффект и тень).  
- Кнопки навигации (`prev`, `next`) и пагинация.  
- Автоматическая прокрутка слайдов (**autoplay**).  

### Используемые технологии:
- **HTML5**, **CSS3 (переменные, flexbox, градиенты)**  
- **Swiper.js v10** (через CDN)  
- **Unsplash API** — для изображений профилей
